# App Store の掲載文（ja：日本語）

文字数の上限は App Store Connect の制限（アプリ名 30 文字、サブタイトル 30 文字、プロモーションテキスト 170 文字、キーワード 100 文字、説明文 4,000 文字）。
見出しはスクリプトが探すので日本語のまま変えない。各見出しの下の最初のコードブロックが登録される文面。

Web 版の公開コピー（<https://roulette.basekeita.com/>）とアプリの「使い方」、[SPEC](../../SPEC.md) から書いた。画面本文と同じく、隠し操作（ステルス）の内容は書かない（SPEC §6.5）。

## アプリ名（30 文字まで）

```
デキレーレット
```

（7 文字）

ホーム画面の表示名（`CFBundleDisplayName`）と同じ。App Store Connect でこの名前が空いているかは、登録するときに人間が確かめる。

## サブタイトル（30 文字まで）

```
迷ったら、まわす。ルーレット・順番決め
```

（19 文字）

Web 版の h1 とタグラインをそのまま使う。

## プロモーションテキスト（170 文字まで）

```
お店選びも、幹事決めも、発表の順番も。決められないときはルーレットをひと振り。候補を入れてスピンすれば、その場で結果が出ます。登録なし・通信なし、データは端末の中だけ。
```

（84 文字）

## 説明文（4,000 文字まで）

```
「今日どこ行く？」
「誰がやる？」
「発表の順番は？」

そんなときに、ルーレットをひと振り。

■ ルーレットで 1 つに決める
候補を入れて「スピン」を押すと、盤面が回ってゆっくり止まり、結果が大きく出ます。項目は 2 個から 24 個まで。盤面はフリックでも回せます。

■ 順番決めで全員の並びを決める
「並べ替え」を押すと、1 位から順に 1 件ずつ発表されます。発表の順番、席順、掃除当番づくりに。もう一度押せば、何度でも引き直せます。

■ こんなときに
飲み会の幹事決め、ランチのお店選び、発表の順番決め、掃除当番、罰ゲーム、じゃんけんやあみだくじの代わりに。登録不要で使えます。

■ 項目は自由に
候補には色や絵文字を付けられます。よく使うリストは名前を付けて保存しておいて、いつでも呼び出せます。

■ 結果はコピーして共有
「結果をコピー」で結果と候補がテキストになってクリップボードへ。「共有」で結果の画像も送れます。グループチャットに貼れば、全員が同じ結果を見られます。

■ 見た目と操作
効果音、触覚フィードバック、止まったスライスの光り方、3D の盤面。細かいところは設定で好みに合わせられます。

■ アプリアイコン
「ネオン」「パステル」「スピナー」「リング」から選べます（iPhone / iPad）。

■ iPhone・iPad・Apple Vision Pro に対応
ダークモードや、大きい文字の設定にも合わせて表示します。

■ データは端末の中だけ
アカウント登録も、通信も、広告も、課金もありません。入力した項目は次の起動でもそのまま残ります（端末のバックアップ（iCloud・パソコン）には含まれ、アプリを削除すると消えます）。

決められないときの、ひと振りを。
```

## キーワード（100 文字まで・カンマ区切り）

アプリ名とサブタイトルに入っている語（デキレーレット・迷ったら・まわす・ルーレット・順番決め）は外した。

```
抽選,くじ引き,ランダム,決定,選択,ランチ,幹事,席順,発表,チーム,あみだくじ,おみくじ,ごはん,じゃんけん,罰ゲーム
```

（61 文字）
